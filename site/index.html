Agentic skincare safety engine

Radiance AI

An agentic recommendation system for cosmetic and skincare products that reads every ingredient list before it recommends anything — flagging allergens, unsafe actives, and health-condition conflicts first.

Directions for use

What it does

A multi-agent workflow drives the core reasoning loop: it interviews the user to build a safety profile, searches a product catalog, runs ingredient safety checks, and generates personalised recommendations — all over a stateless REST API backed by persistent session storage.

Active mechanism

How it works

An agentic LangGraph workflow orchestrates five stages, in order, generating personalised recommendations complete with an AM/PM routine and ingredient-interaction warnings:

Supervisor > Questioner > ProductFinder / WebResearcher > SafetyChecker > Recommender

Backed by Qdrant (vector search), MongoDB (product catalog), and PostgreSQL (sessions, safety rules, EU CosIng ingredient data), with all LLM and embedding calls routed through a LiteLLM proxy so the underlying model provider is swappable.
